INTRODUCING HELIOS

Technology that
works with you.

Helios brings local AI conversation together with voice interaction, persistent context, and connections to supported applications.

The Public Edition is a deliberately scoped version of the assistant, designed to give people useful capabilities while keeping the experience customizable and user-directed.

CAPABILITIES

More than a
conversation window.

01

Local AI conversation

Run supported language models locally through Ollama, keeping the core model interaction on the user's own machine.

02

Voice-first interaction

Speak naturally, use wake-word activation, and interact with Helios without relying solely on typed commands.

03

Context and memory

Maintain conversational context and use supported memory features to make interactions more continuous.

04

Application integrations

Connect supported tools and applications through available integrations and extensions.

05

Modular extensibility

Organize functionality into modules and support third-party extensions, subject to the permissions and safeguards of each extension.

DESIGNED FOR LOCAL USE

Your machine.
Your assistant.

Helios Public uses a local AI runtime and supported models rather than requiring a hosted AI API for its core language-model interaction.

Ollama is installed separately. The installation guide explains the required setup and model configuration. Features that use the internet or connected applications may still communicate with those services when invoked.

USER CONTROL

Capability with
clear boundaries.

Helios Public is intended to keep users in control of sensitive actions through explicit permission prompts and defined restrictions. Users should review the documentation, understand each integration's permissions, and only install extensions from sources they trust.

GETTING STARTED

Before you
begin.

  • Windows 10 or Windows 11 (tested configurations).
  • Ollama installed separately.
  • A supported local model configured as described in the included guide.
  • Python and dependencies installed as specified in the README.

Actual performance and model compatibility depend on your computer's hardware and software configuration. Consult the included documentation before installation.
